# Brand Gamification Decisions

This document defines the final brand, mascot, visual, motion, gamification, and trust rules for the next BudgetMeter redesign.

## 1. Final Brand Personality

BudgetMeter is a Playful Momentum FinTech app.

The brand should feel:

- Fun
- Modern
- Consumer-friendly
- Encouraging
- Fast
- Clear
- Trustworthy
- Polished
- Useful

BudgetMeter should not feel:

- Childish
- Casino-like
- Meme-driven
- Shame-based
- Heavy accounting-focused
- Like a spreadsheet with decoration
- Like a game that happens to show money

The core brand promise is simple:

BudgetMeter helps users understand whether their money is moving forward or slowing down, and how fast.

## 2. Pulsey Mascot Rules

Pulsey is the selected BudgetMeter mascot direction.

Pulsey is a small abstract finance creature that represents:

- Momentum
- Pulse
- Financial heartbeat
- Forward motion
- Calm awareness

Pulsey should be cute but not childish. Pulsey should feel calm, positive, encouraging, and trustworthy.

### Primary Pulsey Role

Pulsey appears mainly during the app launch splash animation for about 3 seconds.

Pulsey may later appear lightly in:

- Onboarding
- Empty states
- Success states
- Weekly recap
- Savings milestones
- Awareness streak moments
- Soft premium education
- Widget artwork if widgets support it later

### Pulsey Restrictions

Pulsey must not:

- Dominate the Home dashboard
- Sit inside the main financial pace number
- Slow down transaction entry
- Interrupt quick income or expense logging
- Joke about negative financial states
- Joke about user money stress
- Shame users for bad financial days
- Become a pet-care or dependency mechanic
- Become a full RPG character system

Pulsey is a brand guide, not the product itself.

## 3. Color Principles

BudgetMeter uses a dark-first visual identity.

Core color direction:

- Background: obsidian / dark navy
- Cards: slate surfaces
- Main accent family: vivid cyan / blue / indigo
- Positive momentum: emerald / green
- Caution: amber
- Negative drain: coral

The palette should feel lively, not pale.

### Color Rules

- Financial meaning must not rely on color alone
- Pair color with copy, icons, layout, and typography
- Use coral for negative drain without making the state feel alarming
- Use amber for caution and attention, not panic
- Use emerald for momentum and progress
- Use cyan / blue / indigo for brand energy and primary actions

### Avoid

- Obvious AI-looking purple/pink gradient overuse
- Childish pastel overload
- Casino-style gold glow
- Neon overload
- Red-only negative states
- Color combinations that reduce readability

## 4. Motion And Haptic Principles

Motion should make the app feel alive without reducing trust.

Allowed motion:

- Short launch splash animation with Pulsey
- Small success animation after successful entry
- Subtle momentum ring progress motion
- Gentle milestone feedback
- Small weekly recap transitions

Allowed haptics:

- Successful income/expense entry
- Savings milestone
- Awareness streak confirmation
- Premium unlock confirmation
- Restore/backup success confirmation

Motion and haptics should be:

- Fast
- Subtle
- Optional where accessibility requires it
- Consistent
- Calm

Avoid:

- Long animations before core tasks
- Repeated celebratory effects
- Loud confetti moments
- Motion that delays transaction entry
- Motion that makes negative states feel scary
- Effects that do not respect reduced motion needs

## 5. Gamification Principles

Gamification should support financial awareness, not replace financial utility.

Gamification should reward:

- Awareness
- Consistency
- Improvement
- Small progress
- Returning to check financial direction
- Understanding the user's money pace

Gamification must not reward:

- Wealth level
- Spending more
- Risk-taking
- Social comparison
- Shame avoidance

BudgetMeter should feel more fun than a budgeting app, but more trustworthy than a game.

## 6. Free Gamification Mechanics

Free gamification mechanics should support the core reason users open BudgetMeter.

v1 free mechanics:

- Momentum ring
- Haptic feedback after successful entry
- Small success animation after entry
- Basic savings milestone
- Awareness streak
- Simple weekly recap

### Awareness Streak

Awareness streak tracks regular check-ins / money awareness.

It should not track:

- Wealth
- Income size
- Perfect spending
- Positive financial days only
- Avoiding expenses

The streak should never make a user feel punished for a difficult financial day.

## 7. Premium Gamification Mechanics

Premium gamification should add depth, personalization, convenience, and motivation.

Premium mechanics can include:

- Richer weekly recap
- Advanced savings milestones
- Multiple goal progress
- Forecast-based progress celebrations
- Widget-based momentum display
- Advanced history and reporting visuals
- Custom category-based insights
- Premium themes
- Accent color packs
- App icon variants
- Chart style options
- Pulsey accent variants

Premium gamification should feel like extra control and personalization, not like the core product was withheld.

## 8. Premium Personalization Rules

Premium personalization should be controlled and coherent.

Allowed premium personalization:

- Accent color packs
- Premium themes
- App icon variants
- Chart style options
- Pulsey accent variants

Not allowed for the current direction:

- Unlimited free color editing
- Arbitrary user-defined palettes
- Customization that breaks readability
- Customization that makes financial states unclear
- Mascot personality systems
- Casino-like premium glow

Premium visual treatment can use:

- Subtle premium glass
- Refined lock/badge treatment
- Soft gold/indigo edge treatment

Premium visual treatment should avoid:

- Loud purple/pink glow
- Casino-style gold
- Cheap shine effects
- Paywall visuals that overpower the core dashboard

## 9. Trust And Accessibility Guardrails

Trust matters more than decoration.

Rules:

- Critical financial numbers must appear on solid or near-solid readable surfaces
- Heavy glass/blur should not sit behind the main pace number
- Home should remain readable at a glance
- The app should not rely on color alone for financial meaning
- Copy should be clear, encouraging, and non-judgmental
- Negative states should use gentle language such as "Slowing down"
- The shared normalized calculation model must power Home, charts, widgets, savings, and recap surfaces
- Do not show fake trends when there is not enough data
- Do not over-promise forecasts
- Local free use should remain clear and trustworthy
- Apple Sign In and Supabase backup/sync should be explained plainly when presented

Accessibility guardrails:

- Support high contrast needs
- Respect Reduce Motion
- Keep tap targets large enough for comfortable mobile use
- Keep chart labels legible
- Avoid tiny text inside dense cards
- Pair semantic color with icons or labels

## 10. What To Avoid

Avoid:

- Heavy budgeting/accounting UI
- Spreadsheet-style dashboards
- Social leaderboards
- Financial competition
- RPG systems
- Casino mechanics
- Punishment loops
- Shame-based streaks
- Mascot dependency mechanics
- Childish mascot behavior
- Jokes about user financial stress
- Loud confetti and excessive celebration
- Forced sign-in before local value
- Forced premium before core value
- Forced bank sync
- Purple/pink AI-style gradient overload
- Pastel-only cute theme
- Casino-style gold premium glow
- Heavy blur behind critical financial data
- Inconsistent calculations across screens

BudgetMeter should be playful, but the money data must always feel serious, clear, and reliable.
